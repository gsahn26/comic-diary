# 📔 네컷일기 — AI 4컷 만화 일기

오늘 있었던 일을 일기로 쓰면, AI가 **기승전결 4컷 웹툰**으로 바꿔 주는 무료 웹앱입니다.

- 🔗 **배포 링크:** https://gsahn26.github.io/comic-diary/
- 📦 **저장소:** https://github.com/gsahn26/comic-diary
- 💸 **비용:** 0원 (API 키 없음, 서버 없음)

## 어떻게 쓰나요?

1. **일기 쓰기:** 오늘 있었던 일을 자유롭게 씁니다. 주인공 생김새(선택)를 적으면 4컷 내내 같은 모습으로 그리려고 노력합니다.
2. **AI로 4컷 나누기:** AI가 일기를 기·승·전·결 4컷으로 나누고, 컷마다 장면 설명, 말풍선 대사, 아래 해설을 만듭니다.
3. **다듬기:** 제목, 대사, 해설, 장면을 마음대로 고칩니다. AI가 실패하면 **직접 4컷 쓰기**로 넘어갑니다.
4. **그림 그리기:** 4컷을 한 장씩 그립니다. 무료 서버는 *45초에 1장*만 허용해서 완성까지 약 3분 걸립니다.
5. **완성:** 2×2 네컷이 한 장의 이미지로 합쳐집니다.
   - 마음에 안 드는 컷은 🔄 **다시 그리기**
   - 대사·해설은 완성 후에도 바로 고칠 수 있음
   - ⬇️ **PNG 다운로드**, 💾 **갤러리에 저장**(이 브라우저에만 저장)

## 기술 구성

| 부분 | 사용한 것 |
| --- | --- |
| 화면 | HTML, CSS, 바닐라 JavaScript (빌드 도구 없음) |
| 4컷 나누기 | [Pollinations.ai](https://pollinations.ai) 텍스트 API (`text.pollinations.ai`, 무료·키 없음), JSON 응답을 관대하게 파싱 |
| 그림 | Pollinations.ai 이미지 API (`image.pollinations.ai`), 웹툰풍 스타일 + 같은 주인공 묘사 + 같은 seed로 캐릭터 일관성 유지 |
| 네컷 합성 | `<canvas>`에 2×2로 배치하고, **한글 말풍선·해설은 앱이 직접 그림** (이미지 AI는 한글을 잘 못 쓰기 때문) |
| 글꼴 | Google Fonts – Gaegu(말풍선·제목), Noto Sans KR(해설) |
| 저장 | `localStorage` 갤러리 (최대 20개, 공간이 부족하면 오래된 것부터 정리) |
| 배포 | GitHub Pages |

## 알아 둘 점 (한계)

- 무료 이미지는 **IP당 45초에 1장** 제한이 있어서 앱이 자동으로 기다렸다가 다음 컷을 그립니다.
- 그림 품질은 무료 모델 수준이고, 오른쪽 아래에 작은 pollinations.ai 워터마크가 들어갑니다.
- 같은 seed와 주인공 묘사를 써도 컷마다 얼굴이 조금씩 달라질 수 있습니다.
- 일기 내용은 4컷 나누기와 그림 생성을 위해 Pollinations 서버로 전송됩니다. 민감한 개인정보는 적지 마세요.

## PoC 보고서 (구축할 만한가?)

만들기 전에 성공 기준을 숫자로 적고, 시험용 일기 10편으로 재 봤습니다. 자세한 내용은 [poc/REPORT.md](poc/REPORT.md)에 있습니다.

| 항목 | 기준 | 결과 | 판정 |
| --- | --- | --- | --- |
| 4컷 형식으로 나뉘는가 | 10편 중 9편 이상 | 8편 | 미달 |
| 일기의 핵심 사건이 들어가는가 | 10편 중 8편 이상 | 7편 | 미달 |
| 주인공이 4컷 내내 같은 모습인가 | 20컷 중 15컷 이상 | 10컷 | 미달 |
| 한 편 완성 시간 | 5분 이내 | 약 200초 | 통과 |

- **결론:** 과제 시연용으로는 동작하지만, 지금 구성(무료 Pollinations)은 성공 기준 4개 중 3개를 넘지 못했습니다.
- **업무 유형:** 일기를 4컷 대본으로 옮기는 단계는 "입력과 전사"에 가깝고, 그림 생성은 네 유형 밖입니다.
- **걸러내기 조건:** 일기가 외부 서버로 나가므로 민감한 일기에는 쓰면 안 됩니다. 그림 모델의 라이선스는 확인하지 못했습니다.
- **아직 안 잰 것:** 기준선(사람이 직접 4컷을 쓰는 시간), 브라우저 안에서 도는 모델.

다시 재려면 `node poc/measure.mjs`를 실행합니다(약 25분, 결과는 `poc/results/`에 새 폴더로 저장).

## 내 컴퓨터에서 실행하기

```bash
cd comic-diary
python3 -m http.server 8930
```

브라우저에서 **http://127.0.0.1:8930** 으로 엽니다.
⚠️ `localhost`로 열면 Pollinations가 봇 확인(Turnstile)으로 요청을 막습니다. 꼭 `127.0.0.1`을 쓰세요.
