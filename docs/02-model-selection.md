# 모델·기법 선정과 이유

작성일: 2026-11-17

## 1. 문제를 단계로 나누기

일기를 4컷 만화로 바꾸는 일은 성격이 다른 세 단계로 나뉜다. 단계마다 맞는 기법이 다르다.

| 단계 | 하는 일 | 고른 기법 | 수업에서 배운 내용 |
| --- | --- | --- | --- |
| 1. 4컷 나누기 | 글을 읽고 사건 4개를 시간 순서로 뽑아 대사·해설·장면으로 정리 | **언어 모델(LLM) + 구조화 출력(JSON)** | 트랜스포머, 토큰과 컨텍스트, 구조화 출력 |
| 2. 그림 그리기 | 장면 설명 문장을 그림으로 | **텍스트-이미지 생성 모델** | AI가 없던 그림을 만들어 내기까지 |
| 3. 합성 | 그림 4장을 2×2로 놓고 한글 말풍선·해설을 얹음 | **AI를 쓰지 않음** (브라우저 `<canvas>`) | — |

## 2. 단계별 선정 이유

### 1단계: 언어 모델 + 구조화 출력

- **왜 언어 모델인가.** 문장을 4등분하는 규칙으로는 안 된다. 시험용 일기 d09는 "저녁에 사과했다. 사실 점심에 다퉜다…"처럼 순서를 뒤섞어 썼다. 이런 글을 시간 순서로 다시 놓으려면 내용을 이해해야 한다. 2차 측정에서 언어 모델은 이 일기를 올바른 순서로 나눴다.
- **왜 구조화 출력인가.** 결과를 화면의 칸(대사, 해설, 장면)에 바로 넣어야 한다. 그래서 문장으로 답하게 하지 않고 정해진 항목만 채운 JSON으로 받는다.
- **측정으로 확인한 것.** JSON 모드를 켜도 형식이 깨질 수 있다(1차 10편 중 2편). 프롬프트에 형식 규칙을 넣은 뒤에는 10편 모두 통과했다. 깨졌을 때를 대비해 파서를 너그럽게 만들고, 한 번 더 요청하고, 그래도 안 되면 직접 쓰는 화면으로 넘어가게 했다.

### 2단계: 텍스트-이미지 생성 모델

- **왜 생성 모델인가.** 일기 내용에 맞는 그림은 어디에도 없으므로 찾는 것(검색)으로는 안 되고 새로 만들어야 한다.
- **주인공을 같게 유지하는 방법.** 이 모델은 앞 컷을 기억하지 못한다. 그래서 4컷 모두에 **같은 주인공 묘사 문장**과 **같은 seed**를 넣었다. 측정 결과 20컷 중 14컷에서 주인공 특징이 유지됐다(기준 15컷에 미달).
- **측정으로 확인한 것.**
  - 프롬프트가 길면 **뒤쪽 내용이 그림에 반영되지 않았다.** 처음에는 스타일 문구를 앞에, 장면을 뒤에 뒀더니 4컷이 모두 같은 그림으로 나왔다. 장면을 앞으로 옮기고 프롬프트를 줄이자 해결됐다. 정확히 몇 토큰에서 잘리는지는 확인하지 못했다.
  - 주인공 묘사를 맨 앞에 두면 옷 색과 안경이 더 잘 지켜진다(d01, d03이 0/4 → 4/4).
  - 한국어 프롬프트는 잘 통하지 않아서 영어로 넣는다.

### 3단계: 한글은 AI에게 맡기지 않는다

- 이미지 생성 모델은 글자, 특히 한글을 정확히 그리지 못하는 경우가 많다고 알려져 있다(이 프로젝트에서 따로 재지는 않았다).
- 말풍선 대사는 한 글자만 틀려도 못 쓰는 결과가 된다. 그래서 이미지 모델에는 "글자 없는 그림"만 맡기고, 대사와 해설은 앱이 한글 글꼴(Gaegu, Noto Sans KR)로 직접 그린다.
- 덕분에 그림을 다시 그리지 않고도 대사를 바로 고칠 수 있다.

## 3. 후보 비교

교안대로 크기만 다른 후보가 아니라 **실행 위치가 다른 후보**를 놓았고, 점수를 매기기 전에 조건으로 먼저 걸렀다.

| 후보 | 실행 위치 | 비용 | 일기가 밖으로 나가는가 | 걸러내기 결과 | 측정 |
| --- | --- | --- | --- | --- | --- |
| **Pollinations 무료 API** (텍스트 + 이미지) | 외부 서비스 | 0원, 키 없음 | 나감 | 조건부 통과 (민감한 글은 넣지 않음) | 1차, 2차 측정함 |
| 유료 API (상용 언어·이미지 모델) | 외부 서비스 | 유료, 키 필요 | 나감 | **탈락.** 이 과제의 조건이 "비용 0원, 서버 없는 정적 사이트"인데, API 키를 정적 사이트에 넣으면 누구나 볼 수 있다 | 안 함 |
| 브라우저 안에서 도는 모델 | 사용자 기기 | 0원 | **안 나감** | 통과 | 아직 안 함 (다음 단계) |
| 사람이 직접 (기준선) | 사람 | 0원 | 안 나감 | — | [03-baseline-comparison.md](03-baseline-comparison.md) |

**Pollinations를 고른 이유:** 조건(0원, 키 없음, 정적 사이트)을 통과한 후보 중 지금 바로 텍스트와 이미지를 둘 다 쓸 수 있는 유일한 후보였다.

**고르면서 감수한 것 (측정으로 확인):**

- 텍스트와 이미지 모두 IP당 45초에 1회 제한이 있다. 한 편에 약 200초가 걸린다.
- 그림에 워터마크가 들어간다.
- 어떤 언어 모델이 응답하는지 공개 정보로 확인하지 못했다. 그림 모델은 받은 파일 정보에 Sana로 찍혀 있었지만 어느 버전인지, 라이선스가 무엇인지 확인하지 못했다.
- 그림체가 요청한 웹툰풍보다 반실사에 가깝게 나온다.

## 4. 다음에 확인할 후보

주일학교 도메인에서는 아이 글이 밖으로 나가지 않는 것이 가장 중요하다. 그래서 다음 확인 대상은 **브라우저 안에서 도는 언어 모델로 1단계(4컷 나누기)를 대신할 수 있는가**이다. 같은 일기 10편과 같은 기준(C1, C2)으로 재면 지금 구성과 바로 견줄 수 있다.
