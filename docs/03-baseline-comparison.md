# 기존 방식과 비교

작성일: 2026-11-17

기존 방식의 시간은 아직 재지 않았다. 그래서 이 문서는 **정성 비교**이고, 숫자로 견줄 수 있는 칸은 비워 두었다.

## 1. 비교 대상

| 방식 | 설명 |
| --- | --- |
| A. 글만 쓰기 | 아이가 글만 써 온다. 그림 없음 |
| B. 아이가 직접 그리기 | 지금의 그림일기 |
| C. 교사가 직접 4컷 대본 쓰기 | 앱의 "직접 4컷 쓰기"로 교사가 대사·장면을 쓰고, 그림만 AI가 그림 |
| D. 네컷일기 (AI가 나누고 그림) | 이 프로젝트 |

## 2. 정성 비교

| 항목 | A. 글만 | B. 아이가 그림 | C. 교사가 대본 | D. 네컷일기 |
| --- | --- | --- | --- | --- |
| 그림을 못 그리는 아이도 결과물이 나오는가 | 그림 없음 | 어렵다 | 나온다 | 나온다 |
| 반에서 함께 보거나 나누기 좋은가 | 어렵다 | 좋다 | 좋다 | 좋다 |
| 아이 자신의 표현이 담기는가 | 글에만 | **가장 잘 담긴다** | 대본은 교사, 그림은 AI | 대본과 그림 모두 AI. 교사가 고칠 수 있음 |
| 내용이 틀릴 위험 | 없음 | 없음 | 낮다 | 있다. 2차 측정에서 핵심 사건은 10편 모두 들어갔지만 어색한 대사가 섞였다 |
| 주인공이 컷마다 같은가 | — | 아이가 그리므로 같다 | AI 그림이라 D와 같다 | 20컷 중 14컷 (기준 미달) |
| 교사의 손이 가는 정도 | 없음 | 없음 | 4컷 대본을 직접 써야 한다 | 입력하고 확인·수정만 한다 |
| 아이 글이 밖으로 나가는가 | 안 나감 | 안 나감 | 장면 설명만 나감 | **일기 원문이 나감** |
| 비용 | 0원 | 0원 | 0원 | 0원 |

## 3. 숫자로 확인한 것과 못 한 것

| 항목 | D. 네컷일기 (측정함) | C. 교사가 대본 (재야 함) |
| --- | --- | --- |
| 4컷 대본이 나오는 데 걸리는 시간 | 12~22초 (2차 10편 중 9편. 1편은 서버 오류로 다시 시도해 69초) | `(측정 필요)` |
| 한 편 완성까지 | 약 200초 | `(측정 필요)` + 그림 약 180초 |
| 대본을 고치지 않고 쓸 수 있는 비율 | 재지 않음 (핵심 사건 포함 여부만 잼) | — |

**기준선을 재는 방법 (10~15분):**

1. 일기 3편을 고른다.
2. 앱에서 "직접 4컷 쓰기"를 눌러 4컷의 대사·해설·장면을 직접 쓰고, 편마다 걸린 시간을 잰다.
3. 같은 일기를 "AI로 4컷 나누기"에 넣고, 나온 결과를 고치는 데 걸린 시간을 잰다.
4. 위 표의 빈칸을 채운다.

## 4. 지금 말할 수 있는 것과 없는 것

**말할 수 있는 것:**

- 그림을 못 그리거나 글만 써 온 아이의 일기도 4컷 만화로 만들 수 있다. 기존 방식 A, B로는 안 되던 일이다.
- AI가 4컷 대본을 만드는 시간은 대부분 12~22초다. 교사가 4컷의 대사·해설·장면 12칸을 직접 쓰는 것보다 빠를 가능성이 높지만, 재지 않았으므로 추정이다.

**말할 수 없는 것:**

- "교사의 시간이 얼마나 줄어드는가"는 기준선을 재기 전에는 말할 수 없다.
- 아이가 직접 그린 그림일기(B)보다 낫다고 말할 수 없다. 아이의 표현이라는 면에서는 B가 더 낫다. 이 도구는 B를 대신하는 것이 아니라 A를 돕는 용도다.
- 시험용 일기는 어른 글이었으므로, 실제 아이 글에서도 같은 결과가 나오는지는 아직 모른다.
