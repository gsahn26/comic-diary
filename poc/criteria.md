# PoC 성공 기준 (측정 전에 작성, 2026-11-17)

이 파일과 [dataset.json](dataset.json)은 측정 스크립트를 돌리기 **전에** 커밋했다. 결과를 본 뒤에 기준이나 정답을 바꾸지 않는다.

## 확인하려는 것

"일기를 쓰면 AI가 4컷 만화로 만들어 준다"가 무료·키 없는 구성(Pollinations)으로 쓸 만한 수준인가.

## 걸러내기 조건 (통과/탈락, 점수에 섞지 않음)

| 조건 | 통과 기준 |
| --- | --- |
| G1. 자료가 어디까지 나가는가 | 일기 원문이 외부 서비스로 나가는 사실을 사용자가 알고 동의할 수 있어야 한다. 개인정보를 적지 말라는 안내가 화면에 있어야 한다. 민감한 일기(타인 실명, 건강, 신앙 고백 등)를 쓰는 용도라면 **탈락**으로 본다. |
| G2. 라이선스·이용 약관 | 개인 비상업 과제로 쓰는 것이 약관상 허용되어야 한다. 확인한 날짜와 링크를 적는다. |

## 성공 기준 (숫자)

| # | 항목 | 기준 | 재는 방법 |
| --- | --- | --- | --- |
| C1 | 4컷 형식 | 일기 10편 중 **9편 이상**이 첫 응답에서 4컷 JSON으로 읽힌다 | 스크립트가 자동 판정 (앱과 같은 `core.js` 파서) |
| C2 | 내용 | 일기 10편 중 **8편 이상**에서 정답 사건의 **75% 이상**이 4컷(해설·대사·장면)에 들어간다 | 정답 사건 목록과 대조해 사람이 채점 |
| C3 | 주인공 일관성 | 그림을 그린 20컷 중 **15컷 이상**에서 주인공에게 정해 둔 특징 2개가 모두 보인다 | 그림을 보고 사람이 채점 |
| C4 | 시간 | 한 편(나누기 + 번역 + 그림 4장) 완성이 **5분 이내** | 스크립트가 측정 |

어려운 일기 3편(d08 너무 짧음, d09 순서가 뒤섞임, d10 사건보다 감정 위주)을 일부러 넣었다.

## 기준선

지금 하는 방식 = 사람이 직접 4컷 대본을 쓰는 것(앱의 "직접 4컷 쓰기"). 같은 일기로 직접 쓰는 데 걸리는 시간을 재서 C2·C4와 견준다.
